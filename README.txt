BGTbali Launcher weboldal – telepítés

FÁJLOK
- index.html: a weboldal tartalma
- style.css: piros-fekete dizájn és mobilos megjelenés

FONTOS A LETÖLTÉSHEZ
1. Másold a saját launcher EXE-fájlját ebbe a mappába.
2. Nevezd át pontosan erre: launcher.exe
3. A weboldal letöltés gombja erre a fájlra mutat.

KAPCSOLAT / HIBAJELENTÉS
Az index.html fájlban keresd ezt: href="#" id="report-link"
Cseréld le a # jelet a saját Discord-meghívódra vagy kapcsolatfelvételi linkedre.

INGYENES TÁRHELY
A fájlokat egy statikus weboldalakat fogadó ingyenes tárhelyre lehet feltölteni, például GitHub Pages vagy Netlify. Az EXE-t a tárhely szolgáltatási korlátaitól függően külön fájltárhelyen is tarthatod; ilyenkor a letöltési hivatkozást az index.html fájlban módosítani kell.

Megjegyzés: a jelenlegi hírek mintaszövegek, a letöltéshez pedig még hozzá kell adnod a saját EXE-fájlodat.
